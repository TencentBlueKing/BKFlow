# V1.12.1 Release Notes

<!-- Source changes: V1.12.0 / 5ede1a629ab8895ce6639a9674b79ae2b4c7d09f through upstream/master / 7008e9524cbc38c0e759411e88c8d31e502920fa. The packaging pipeline fix is listed separately. -->

### Added

- [ Added ] The system administrator username is configurable. It defaults to `admin`, and administrator checks continue to recognize the legacy usernames `admin` and `bk_admin`. [#1024](https://github.com/TencentBlueKing/BKFlow/pull/1024)

### Improved

- [ Improved ] Upgraded the Python runtime to 3.11.17. [#1025](https://github.com/TencentBlueKing/BKFlow/pull/1025)
- [ Improved ] Upgraded the application descriptor to v3. The packaging descriptor renderer supports both v2 and v3. [#1034](https://github.com/TencentBlueKing/BKFlow/pull/1034)

### Fixed

- [ Fixed ] Fixed missing artifact version numbers when the SES Smart packaging pipeline reads a v3 application descriptor. The pipeline accepts `appVersion` and the legacy `app_version` field and stops packaging if the version is missing or empty.
