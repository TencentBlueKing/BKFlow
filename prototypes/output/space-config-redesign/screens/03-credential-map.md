# 网关凭证 · 凭证联动（credential_map 复合控件）

[[ 空间配置 > 权限与安全 > 网关凭证 ]]

::: card
#### 用途
按作用域选用「凭证管理」中的 BK_APP 凭证访问统一 API 网关；本质是一张「作用域 → 凭证」的路由表。

#### 影响
调用网关时按此表取凭证鉴权；未命中作用域时回落到默认凭证。

[前往凭证管理](#)
:::

::: card

- prod-bkapp-default（BK_APP · 空间级）
- ci-deploy-bkapp（BK_APP · 空间级）
- + 新建凭证…

:::

<!-- ❶ 默认凭证下拉列出本空间 BK_APP 凭证（名称 + 类型 + 作用域级别），可搜索；末项「+ 新建凭证」就地打开凭证管理侧滑，建完自动回填。 -->
