# 并行网关变量聚合 · 分支联动与异常态

[[ 流程编辑 > 订单多渠道审批 ]]

> **入口说明（非独立页面）**：本屏不是单独菜单。三类场景分别从现有操作触发，叠在流程编辑画布上。

### 入口总览

| 场景 | 用户操作入口 | 出现形态 |
|------|--------------|----------|
| A 同分支重复 | 节点配置 → 输出参数勾选/填写已存在的同分支 KEY | Dialog / 表单校验错误（阻断） |
| B 删除来源 | 画布选中并行分支节点 → 删除 | 删除确认 Dialog（含聚合影响） |
| C 新增来源 | 新分支节点配置 → 输出勾选已是聚合变量的 KEY | 节点配置内成功提示（自动并入） |
| 健康状态 | 顶栏设置 → **全局变量**侧滑列表（聚合徽标/建议降级） | 事后查看，非创建向导 |

::: card
#### 入口示意（流程编辑画布）

画布：并行网关 + 分支 A/B/C …

- 点分支节点打开 **节点配置** → 触发 A / C
- 点节点菜单 **删除** → 触发 B
- 点顶栏 **全局变量** 图标 → 查看聚合状态徽标（健康检查）
:::

<!-- ❶ 健康检查入口：流程编辑顶栏「全局变量」侧滑列表，展示聚合方式、来源数量、建议降级等状态；不是独立「健康检查」页。 -->

::: card
#### 场景 A：同分支重复 key（入口：节点配置输出参数）

节点：分支 A · 库存检查（节点配置侧滑打开）

输出 KEY
[result________________]{error}

((不可聚合)){error}

同一分支内已存在 `result` 输出。请改名或复用当前节点内的已有输出。

:::

<!-- ❷ 同分支重复在节点配置内阻断，不进入聚合向导。 -->

::: card
