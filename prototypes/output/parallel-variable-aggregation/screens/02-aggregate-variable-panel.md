#### 聚合方式

- (*) 收集为列表（默认）
- ( ) 合并为字典

列表形态：`[branch_1, branch_2]`

字典形态：`{branch_1: value, branch_2: value}`

顺序规则
((稳定)){success}

按并行网关中分支从上到下、从左到右的稳定顺序收集。

运行期命名空间
| 逻辑 KEY | 运行期写入 | 展示名 |
|----------|------------|--------|
| result | result@branch_1 | 分支 A · 华南区资源检查 |
| result | result@branch_2 | 分支 B · 华北区资源检查 |

:::

<!-- ❷ 聚合策略挂在变量自身，一变量一策略；分支侧不重复配置。默认列表模式适合「全部分支结果汇总」场景。 -->
<!-- ❸ dict 模式的分支标识只读展示，由引擎运行期命名空间自动填充；用户不手填 branch key。 -->

::: card
