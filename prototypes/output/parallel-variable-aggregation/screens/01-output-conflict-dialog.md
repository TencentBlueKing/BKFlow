#### 变量配置 · 步骤 1/3（选「聚合」时）

提示：已存在同名全局变量 `result`，且当前节点位于另一个并行分支。

创建方式
[聚合到 result（推荐）______v]
- 聚合到 result（推荐）
- 复用 result（沿用现状，后写覆盖前写）
- 手动创建（改个名字）

步骤指示
((1 创建方式)){primary} — 2 聚合方式 — 3 引用确认

影响范围
| 来源分支 | 节点 | 输出 |
|----------|------|------|
| 分支 A | 华南区资源检查 | result |
| 分支 B | 华北区资源检查 | result |

实时校验
((通过)){success} 跨分支可聚合 · 同分支不可 · 下游 3 处需确认

::: row {right}
[取消] [下一步：设置聚合方式]*
:::
:::

#### 变量配置 · 不聚合时（复用 / 手动创建）

创建方式
[复用 result（后写覆盖前写）______v]
- 聚合到 result（推荐）
- 复用 result（后写覆盖前写）  ← 当前
- 手动创建（改个名字）

步骤指示
((1 创建方式)){primary} — ((2 聚合方式)){disabled} — ((3 引用确认)){disabled}

说明：未选择「聚合」时，步骤 2 / 3 不可进入；「下一步：设置聚合方式」按钮**置灰禁用**。

底栏改为单步确认（对齐现网 ReuseVarDialog）：
::: row {right}
[取消] [确定]*
:::

选手动创建时：展示名称/KEY 输入，确定时仍校验 KEY 不重复；同样无步骤 2/3。
:::
