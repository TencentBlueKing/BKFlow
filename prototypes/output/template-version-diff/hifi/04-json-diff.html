JSON 对比

在设计稿 01 的底栏点「JSON 对比」，或在设计稿 03 点「查看 JSON 片段」（直接定位到该节点）。
1JSON 对比需要主动进入，面包屑为「发布流程 / JSON 对比」；默认入口始终是总览。
2分为「执行字段」和「画布字段」两个范围。画布字段只有节点位置和连线锚点（location、line），与总览里的「画布调整」一致。
3只列出有变化的字段路径和前后值，不展示整棵流程树。
4节点 ID 后面标注节点名和变化类型，方便和画布对应。
5新增、删除的节点和连线默认折叠，展开后显示完整内容。
6「复制差异」复制的内容包含基线版本号、草稿保存时间和字段路径，便于排障。
