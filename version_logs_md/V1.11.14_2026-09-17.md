# V1.11.14 版本更新说明

<!-- 基线：V1.11.13 / f759c8dcc11d4d9a134676154869501b0e9108ed；对比 master 6098d9d0959e7e0f7d6996972df783118434e871，并包含本次出包规范整改。版本声明待合入后以新标签出包，不移动 V1.11.13。 -->

- [ 新增 ] 支持单/多租户配置，按租户隔离空间、流程、任务、插件目录和内部模块调用；保留旧单租户请求及历史资源兼容 (#927)
- [ 新增 ] 接入租户用户组件、个人中心、平台用户时区及租户审批初始化，通知和审批支持新平台接口 (#927)
- [ 新增 ] 业务凭证支持通过 `BKFLOW_CREDENTIAL_CIPHER=SM4` 写入 SM4-GCM 密文，继续兼容历史 AES 密文；启用前需升级所有凭证读写服务 (#932)
- [ 优化 ] 标准 Smart 包的 APP_Code 统一为 `bk_flow`，提供打包描述生成器及环境配置，保留上云存量应用身份、网关和模块地址 (#932)
- [ 优化 ] 平台协议与租户模式分离，新平台单租户和多租户均使用 APIGW；旧单租户平台可配置 `BKFLOW_PLATFORM_API_MODE=legacy` 保留 ESB 通知、人员选择、语言和审批 (#932)
- [ 优化 ] 统一识别内部时区头、`blueking-timezone`、用户 Cookie/session 及平台时区，忽略非法时区值；新周期计划保存用户时区，编辑时保留原计划时区 (#932)
- [ 修复 ] 多租户超管授权仅允许已登录且归属 system 租户的用户；新增同租户空间管理员授权命令 (#932)
- [ 修复 ] 子任务快照准备对瞬时传输及 502–504 故障进行有限重试，并将外部调用移出写事务，保留租户上下文 (#925) (#927)
- [ 修复 ] 完善插件目录同步范围、历史快照归属、嵌套子流程及部署凭证边界，必需迁移失败时中止发布 (#927)
- [ 文档 ] 按已合入代码更新空间配置与 API 插件验证说明 (#931)
- [ 文档 ] 补齐英文 README、94 篇英文 API 文档、中英文当前版本日志和租户错误翻译；文档入口支持按语言及部署版本配置 (#932)

升级说明：Interface、各 Engine 及统计库分别执行所属迁移。开启多租户前完成存量租户归属核验与回填；新平台单租户审批初始化 `default`。旧上云环境升级时显式配置兼容协议并保留原密钥。详细步骤见 [出包与兼容说明](../docs/specs/2026-09-17-app-code-compatibility-design.md)。
