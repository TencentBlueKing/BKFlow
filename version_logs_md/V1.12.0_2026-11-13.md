# V1.12.0 版本更新说明

本版本汇总自 V1.8.1 以来的主要新增、优化和修复。

### 新增

#### 流程编排与版本管理

- [ 新增 ] 支持按阶段（Stage）编排流程，可以拖拽阶段、作业和节点，复制节点参数，并在执行页面查看阶段和子流程。
- [ 新增 ] 支持在流程中引用子流程，选择子流程版本，展开查看节点，并按循环次数或循环参数执行子流程。
- [ 新增 ] 增加循环子画布节点，支持嵌套编排、循环规则、变量引用和输出配置。任务详情可以查看子画布状态、循环执行记录及输出。
- [ 新增 ] 流程支持版本管理，提供草稿、自动保存快照、历史版本查询、发布和回滚，以及过期自动保存快照的清理能力。
- [ 新增 ] 增加标签管理，流程和任务可以关联标签，按标签筛选，并查询标签树及引用数量。

#### 流程调试

- [ 新增 ] 支持全局调试和单步调试，可以选择执行节点、配置模拟结果（Mock）、注入失败、编辑上下文变量，以及重置、终止和查询调试历史。
- [ 新增 ] 条件网关支持单步调试和分支命中结果展示，全局调试可以查看网关状态。
- [ 新增 ] 调试结果单独保存流程、节点名称、原始配置输入和实际执行输入。配置修改后可标记结果是否需要重新调试，并提供存量结果快照的预览和回填工具。

#### 插件与变量

- [ 新增 ] 接入标准运维开放插件 V4，支持分类、搜索、业务版本选择及插件原生表单，兼容 V2/V3 协议。开放插件支持执行快照、同步执行、异步轮询、回调和取消运行。
- [ 新增 ] API 插件可以配置多个来源、访问凭证和请求用户，并验证分类、列表及元数据接口。蓝鲸插件支持二次授权确认和使用范围控制，插件目录支持定时同步及空间内启停。
- [ 新增 ] 增加赋值、消息通知和 Python 代码执行等内置节点，决策表支持导入和导出。内置插件可以按系统配置开放给指定空间。
- [ 新增 ] 支持空间变量和密码类型变量，密码变量提供加密输入、变量引用及脱敏展示。文本输入支持变量联想，下拉框变量支持远程数据源，URL 支持变量渲染。

#### 触发器与通知

- [ 新增 ] 增加定时触发器和周期任务，支持周期表达式、时区配置及执行次数管理；空间可以配置是否允许同一流程使用多个定时触发器。
- [ 新增 ] 扩展 Webhook 事件，支持流程发布，以及任务创建、回调、暂停、恢复和撤销等事件通知。
- [ 新增 ] 流程支持 HTTP 回调，在任务成功或失败后通知外部系统。任务详情可以查看投递时间、事件、结果、状态码及返回信息。

#### 多租户、权限与凭证

- [ 新增 ] 支持单租户和多租户配置，按租户隔离空间、流程、任务、插件目录和内部模块调用，并兼容原有单租户请求和历史资源。
- [ 新增 ] 接入租户用户组件和个人中心，通知、审批及语言设置支持新平台接口，周期计划支持保存用户时区。
- [ 新增 ] 凭证管理支持应用凭证、登录态凭证、Basic Auth 和自定义凭证，可以设置使用范围、加密保存和更新，并传给任务及模拟执行使用。
- [ 新增 ] 业务凭证支持通过 `BKFLOW_CREDENTIAL_CIPHER=SM4` 写入 SM4-GCM 密文，继续读取历史 AES 密文。启用前需要升级所有凭证读写服务。
- [ 新增 ] 接入蓝鲸 PaaS KMS，平台开启 `BKPAAS_KMS_ENABLED=true` 并提供密钥文件后，可以在进程启动时解密敏感配置。
- [ 新增 ] 支持组合 Token，一次申请可以授予多个资源权限，兼容原有单资源申请；流程可以绑定蓝鲸应用，通过应用凭证发起调用。

#### 网关接口与运营统计

- [ 新增 ] 提供简化 JSON 和 A2Flow v2 创建流程接口，以及协议校验、插件列表和插件表单结构查询接口。
- [ 新增 ] 补充流程批量删除、版本管理、草稿及自动保存快照、触发器、画布排版、空间变量、标签、插件配置和任务删除等网关及 SDK 接口。
- [ 新增 ] 流程列表支持按多个流程 ID、标签、创建人和更新人筛选。任务列表支持按状态、任务 ID 列表、标签、来源及子任务条件筛选，并可展开查看子流程任务。
- [ 新增 ] 增加运营统计，按流程、任务和插件采集数据，支持历史回填、定时汇总和独立统计数据库，并接入 BK-Vision 系统及空间统计看板。

#### 任务卡住后的检查和处理

- [ 新增 ] 提供长时间无进展、执行或轮询丢失、回调异常等任务的检查和处理能力，可以查看诊断案例并在预检查、权限校验和操作记录约束下执行恢复。
- [ 新增 ] 检测、防重复执行检查、恢复和告警提供统一配置入口。未配置新旧开关时相关能力默认关闭；已有旧配置继续生效。自动恢复还需配置允许处理的空间和异常类型，详见[开关与迁移说明](../docs/guide/stuck_governance_switches.md)。

### 优化

#### 使用体验与接口

- [ 优化 ] 空间配置改为按类型填写的表单，展示配置说明和默认值，支持参数校验、恢复默认及 Token 有效期上限配置。
- [ 优化 ] 优化画布拖拽、节点复制、子流程高亮和执行详情展示，任务详情可以快速跳转到流程编辑页面；嵌入页面支持控制跳转按钮及画布类型。
- [ 优化 ] 调试任务默认不出现在普通任务列表中，也不计入运营统计；按任务 ID 查询时仍可读取。完善输入校验、流程树静态检查和错误提示。
- [ 优化 ] HTTP 节点支持 JSON 转义；插件配置和节点详情优先使用对应插件的表单及实际执行数据。补齐中英文接口文档，帮助入口支持按语言和部署版本配置。

#### 执行与排查

- [ 优化 ] Python 代码节点改为独立子进程执行，支持超时终止、内存限制和并发控制，兼容常见特殊返回类型、时区及特殊字符，并支持传递前筛选输出。
- [ 优化 ] 增加任务和插件调用链追踪，支持创建任务时传入自定义属性及执行时补充属性，便于对照上下游日志。
- [ 优化 ] 子任务快照准备对瞬时传输和 HTTP 502–504 故障进行有限重试，将外部调用移出数据库写事务，并保留租户信息。

#### 部署与兼容

- [ 优化 ] 运行环境升级为 Python 3.11、Django 4.2，采用 bamboo-pipeline 4.0.6、bamboo-engine 3.0.7 及适配的 Celery、Webhook 依赖，保留子画布、循环和任务检查处理能力。
- [ 优化 ] 提供打包应用标识和网关名称的配置方式，支持保留存量应用、模块地址和密钥。旧单租户平台可设置 `BKFLOW_PLATFORM_API_MODE=legacy`，继续使用原有通知、人员选择、语言和审批接口。
- [ 优化 ] 统一读取用户时区，忽略非法值；新周期计划保存用户时区，编辑未提交时区时保留原计划设置。

### 修复

#### 流程编排与执行

- [ 修复 ] 修复节点连线信息丢失导致保存失败、复制或框选节点异常、部分阶段未渲染，以及条件分支残留退回节点信息的问题。
- [ 修复 ] 修复子流程创建任务回调异常、嵌套循环次数互相影响、切换子流程后画布状态丢失，以及子流程图标或名称显示错误的问题。
- [ 修复 ] 修复版本发布重复、版本号计算、复制流程版本不正确，以及回滚后子流程引用不一致的问题。
- [ 修复 ] 修复失败节点无法重试或跳过、任务节点详情持续加载，以及特殊返回值无法序列化的问题。完善读取执行数据发生内存异常时的提示。

#### 调试结果

- [ 修复 ] 修复调试响应格式、等待状态同步、终止后节点状态残留，以及空闲调试被误提示为已终止的问题。
- [ 修复 ] 修复单步调试缺少画布位置、子画布调试和存量调试快照兼容问题，补齐原始配置输入与执行输入。
- [ 修复 ] 修复配置变更标记不准确的问题，外部连线变化和未执行的新节点不再误报结果失效；取消 Mock 时清理节点结果和产出变量，并处理与启动调试同时操作的情况。

#### 插件、变量与参数

- [ 修复 ] 修复开放插件默认版本选择、执行详情表单加载、创建任务参数丢失，以及 V4 轮询配置校验问题。
- [ 修复 ] 修复旧 API 插件已勾选参数和旧变量表单的兼容问题，以及下拉框多选标签、远程数据凭证和节点输入回显异常。
- [ 修复 ] 修复删除节点后输出变量残留、更新变量读取旧节点、输出初始值和日期时间范围类型不正确的问题。

#### 权限与安全

- [ 修复 ] 修复空间管理员、流程详情及预览、模拟执行、控制类配置和 PATCH 保存流程等操作的权限校验问题，完善资源所属空间及租户的检查。
- [ 修复 ] 修复 Token 并发申请、同一资源续期、历史授权迁移及过期清理异常，完善多租户管理员授权和历史快照归属校验。
- [ 修复 ] 为 Mako 表达式增加根标识符白名单，HTTP 节点增加允许访问域名的检查，插件请求日志屏蔽请求头中的敏感认证信息，并收窄接口返回的内部字段。

#### 页面、定时任务与部署

- [ 修复 ] 修复周期任务时区、执行计数、触发器更新失败回滚、删除流程后的关联清理，以及更新未提交字段被覆盖的问题。
- [ 修复 ] 修复 PaaS 环境查询日志为空、旧 Engine 缺少子任务接口或任务标签字段、首次访问页面未下发 CSRF Cookie，以及静态图片加载导致页面空白的问题。
- [ 修复 ] 修复 Django 4.2 下前端路由返回 500、统计数据库注册时机和 MySQL 5.7 连接兼容问题；必需迁移失败时中止发布，缓存表已存在时继续部署。
- [ 修复 ] 修复全局配置加载的路径和变量引用，按实际应用标识获取配置，并使用远程配置提供的品牌及版本信息。
