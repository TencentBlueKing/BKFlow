## 2026-09-24 高保真稿修订

低保真线框与简易稿升级为高保真稿（`designs/01`–`08`），线框 `screens/`、`shots/` 移除。以下修订覆盖下方 2026-07-09 记录中的对应条目：

1. **总览改为单画布叠加**：按草稿布局绘制，新增绿框、修改黄框，删除的节点以红色虚线框留在基线位置；新增连线绿色实线，删除连线红色虚线。左右对比只用在字段对比。
2. **弹窗标题与面包屑**：总览及各状态为「发布流程」；字段对比为「发布流程 / {节点名}」；JSON 对比为「发布流程 / JSON 对比」。不再使用「发布确认 / 版本差异总览 / …」三级面包屑。
3. **对比对象标注**：差异区顶部写明基线的发布时间，以及草稿的保存时间和保存人。
4. **统计口径**：新增 / 删除 / 修改 / 连线变化四类；只影响画布布局的改动（`location`、`line`）不计入，收在清单底部「画布调整」。
5. **JSON 对比**：分「执行字段 / 画布字段」两个范围，只列有变化的字段路径与前后值，节点 ID 后标注节点名；「复制差异」附带基线版本号、草稿保存时间与字段路径。
6. **新增状态**：只调整布局（06）、首次发布（07）、差异计算失败（08）。计算失败时不阻断发布，发布前二次确认。
7. **待确认**：与新增、删除节点相连的连线是否单独计入「连线变化」（当前设计为不计入）；节点名称、连线显示名等只影响展示的字段是否按执行变更计入（当前设计为计入）。

## 2026-07-09 修订要点
