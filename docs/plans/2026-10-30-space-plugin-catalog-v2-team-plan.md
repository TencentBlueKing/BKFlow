## 五组关键验证

| 验证组 | 代表性检查 |
| --- | --- |
| 状态与并发 | 推荐满额含失效；两管理员争最后名额；检查后被停用；旧失败结果晚到 |
| 数据与迁移 | 来源 401 条跨页；部分页失败；一空间失败另一空间成功；重跑保留人工改动 |
| 引用与保存 | 6 个发布＋2 个仅草稿＝8；同名不同节点；同插件新增节点；无草稿/仅历史 |
| 两模块与页面 | Interface/Engine 各自入口；快照与预检仍工作；目录批量保存、版本定位、两画布参数 |
| AI | 空、错误、越界、过期、重复；增量不动存量；自由模式限范围；保存后不可撤销 |

**串联验收：** 新插件待审核 → 启用并推荐 → 首次超时失效且占推荐名额 → 恢复原状态 → 主动停用清推荐 → 存量可编辑运行、新增被拦截 → 删除目录移未分类 → 再启用回填未分类。
